# Nexmart Branding Rule

CRITICAL RULE:
- NEVER overwrite `index.html` or any other `.html` files in this project with raw templates like `index_original.html`. 
- `index_original.html` is an old, unbranded Dropship.io template. Using it will wipe out the Nexmart branding.
- Always preserve the Nexmart branding ("NexmartShop.ai", correct logos, and updated messaging).
- Do not revert the website back to Dropship.io templates.
- If you need to restore or edit the global navigation or mega-nav, ensure you are using the properly branded Nexmart `global_elements` and not the raw template ones.
